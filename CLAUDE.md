# CLAUDE.md — Buku Wisuda STIA Amuntai 2026

Baca `AGENT.md` sebagai sumber kebenaran utama sebelum mengerjakan tugas.

## Aturan kerja
- Ikuti ukuran A5 portrait, tema “Untukmu Cinta”, palet resmi, gaya futuristic/glassmorphism, dan layout empat wisudawan per halaman.
- Jangan mengubah keputusan final atau mengarang data institusi/wisudawan.
- Data dummy hanya untuk pengujian dan harus diberi label.
- Jangan menimpa data sumber asli; simpan hasil olahan pada folder yang sesuai.
- Utamakan file editable dan kompatibel dengan Adobe InDesign.
- Jangan menyatakan file siap cetak sebelum pemeriksaan visual, preflight, dan konfirmasi spesifikasi percetakan.
- Untuk skrip, jelaskan prasyarat, cara menjalankan, batasan, dan status pengujian.
- Sebelum merename/memindahkan file, periksa dampak pada links dan Data Merge.
- Jika ada konflik, ikuti `AGENT.md` dan keputusan eksplisit terbaru pemilik proyek; tanyakan bila masih ambigu.

## Checklist akhir
1. Sesuai brief dan palet resmi?
2. Data/foto asli aman?
3. Output berada di folder yang benar?
4. File benar-benar dibuat dan bisa dibuka?
5. Langkah manual atau keterbatasan sudah dijelaskan?
